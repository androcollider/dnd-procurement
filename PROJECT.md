# Учебный проект

Тема: «Разработка веб-приложения для сравнения предложений поставщиков материалов и производственных подрядчиков ООО „ДНД Трейд“».

## Задача

Закупщик вручную собирает условия компаний и выбирает предложение с учётом полной стоимости, сроков и ТЗ. Приложение помогает сопоставить условия в одной карточке и сохранить обоснование решения. Снижение числа срывов сроков — предполагаемый эффект, который ещё требует проверки на практике.

Локальный MVP реализован, результаты автоматических проверок — в TESTING.md. Ручная приёмка на Windows и визуальная проверка приложения остаются открытыми. Дополнительные истории Release1 не включены в текущую реализацию.
