# ДНД Трейд — сравнение предложений

Учебный проект по курсу «Управление жизненным циклом ПО». Самостоятельное веб-приложение для сравнения предложений поставщиков тканей и подрядчиков по изготовлению или переработке изделий по ТЗ.

## MVP

1. Создать закупку материала или производственной работы.
2. Записать количество, срок получения и требования ТЗ.
3. Вручную внести предложения компаний.
4. Сравнить полную стоимость, срок получения и соответствие ТЗ.
5. Выбрать исполнителя и сохранить обоснование.

Одна позиция в закупке, рубли, единая основа цен. Итог = количество × цена + доставка + дополнительные расходы. Неизвестные данные не считаются нулём. Соответствие ТЗ проверяет человек.

## Границы

Без интеграций с 1С, Битриксом, почтой и мессенджерами. Номер заказа 1С вводится как текст. Без регистрации и разграничения прав в первой версии. Используются только учебные примеры и вымышленные контрагенты.

## Организация разработки

- 8 историй MVP, 4 истории Release1.
- Три планируемых спринта отмечены метками sprint-1, sprint-2, sprint-3.
- Статусы: Запланировано → В работе → Проверка → Готово.
- Каждая история MVP содержит критерии приёмки и список задач.
- Дополнительные задачи: окружение, прототип, сквозная проверка.
