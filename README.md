# ДНД Трейд — закупки

Учебное веб-приложение для сравнения предложений поставщиков ткани и подрядчиков по изготовлению / переработке изделий. Пять экранов, ввод вручную, локальная база SQLite. Без регистрации и интеграций.

## Запуск на Windows

1. Установите Python 3.10 или новее с официального сайта Python.
2. Распакуйте проект в обычную папку, доступную для записи.
3. Запустите `start-demo.bat`, чтобы посмотреть учебную закупку с тремя предложениями, либо `start.bat` для работы с пустой базой.
4. Браузер откроет `http://127.0.0.1:8765`. Окно сервера оставьте открытым. Для остановки нажмите Ctrl+C.

Дополнительные библиотеки, Node.js и интернет при работе не требуются. Если команда `py` недоступна, используйте `python app.py` в терминале из папки проекта.

Linux / macOS: `python3 app.py --demo`. Другой порт: `python app.py --port 8766`.

## Возможности

- Создание и редактирование закупки: материал или работы, количество, единица, требуемая дата, номер заказа, ТЗ.
- Список закупок с поиском по названию и номеру заказа.
- Создание и редактирование предложений: цена, доставка, дополнительные расходы, сроки, оплата, соответствие ТЗ, комментарий.
- Сравнение стоимости всей партии и даты получения, предупреждения об опоздании, неизвестных условиях и отклонениях от ТЗ.
- Сохранение выбранной компании и обязательного обоснования. Выбор с рисками требует явного подтверждения.
- После изменения выбранного предложения или объёма, срока, ТЗ закупки решение помечается для повторной проверки.
- Проверка версий записей защищает от перезаписи устаревших данных в нескольких вкладках.

## Правила расчёта

Полная стоимость = количество × цена единицы + доставка всей партии + дополнительные расходы. Денежные значения хранятся в копейках, округление до копейки — HALF_UP. Количество допускает три знака после запятой.

Пустое денежное поле означает «не уточнено». Для бесплатной доставки явно введите 0. Пока часть стоимости неизвестна, общий итог не рассчитывается. Все суммы — в рублях на одинаковой основе налогообложения; состав цены закупщик уточняет вручную.

Дата получения = дата готовности / отгрузки + календарные дни доставки. Приложение сравнивает её с требуемой датой. Производственные календари, фактическое исполнение и автоматический выбор победителя не входят в MVP. Соответствие ТЗ оценивает закупщик.

## Данные и резервная копия

Изменения сохраняются сервером в `data/dnd.sqlite3`. После закрытия браузера и перезапуска данные остаются. `--demo` добавляет вымышленные учебные данные только в пустую базу, повторный запуск не создаёт дубликатов.

Резервная копия: `python app.py --backup backups/dnd-2026-11-16.sqlite3`. Укажите новое имя: существующий файл не перезаписывается. Для восстановления остановите сервер и замените `data/dnd.sqlite3` резервной копией. Не удаляйте папку `data` при обновлении приложения.

Это локальная версия для одного рабочего места. Сервер слушает только 127.0.0.1. Вход, роли, общий доступ по сети, синхронизация между компьютерами и обмен с 1С / Битрикс не реализованы. Не размещайте этот сервер в интернете. Данные и резервные копии не входят в репозиторий.

## Проверки

`python -m unittest discover -s tests -v`

Тестируются полный цикл закупки, восстановление данных новым экземпляром хранилища, расчёт и округление, неизвестные условия, риски, пересмотр решения, устаревшие изменения, связь предложения с закупкой, валидация, демонстрационные данные, резервная копия и HTTP API.

## Структура

- `app.py` — HTTP API, SQLite, валидация, расчёты, резервное копирование.
- `static/` — интерфейс на HTML, CSS и JavaScript.
- `tests/test_app.py` — автоматические проверки стандартной библиотекой unittest.
- `start.bat`, `start-demo.bat` — запуск Windows.
