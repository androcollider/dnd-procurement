# Проверка MVP — 16.11.2026

Автоматические проверки выполнены на Linux, Python 3.12.14 и Node.js.

- `python -m unittest discover -s tests -v`: 12 тестов, успешно.
- `python -m py_compile app.py`: успешно.
- `node --check static/app.js`: успешно.
- `node tests/test_frontend.cjs`: проверка формирования пяти экранов, поиска, экранирования HTML, расчётных значений и подтверждения рисков в VM. Это не проверка реального браузера.

Тесты используют временные базы и не меняют пользовательские данные. Проверяются сохранность данных при повторном открытии базы, резервная копия, API и ограничения локального доступа.

Визуальная проверка в браузере и запуск Windows .bat не выполнены: доступ браузера к локальному адресу ограничен средой проверки, Windows здесь отсутствует.

## Ручная приёмка на компьютере пользователя

1. Запустить `start-demo.bat`, открыть учебную закупку.
2. Добавить и изменить предложение, проверить появление данных в сравнении.
3. Выбрать «Вектор Текстиль»: итог 258 000 ₽, получение 08.12.2026, соответствует ТЗ. Ввести обоснование и сохранить выбор.
4. Изменить срок или цену выбранного предложения: решение должно требовать повторной проверки.
5. Создать закупку работ, внести своё ТЗ и предложение с незаполненной доставкой: итог должен требовать уточнения.
6. Выбрать предложение с риском: потребуется подтверждение предупреждений.
7. Закрыть сервер, запустить снова: закупки и решение должны остаться.

В этой версии нет регистрации, интеграций, сетевого многопользовательского режима и контроля фактической поставки. Это согласованный локальный MVP.
